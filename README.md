# Сайт «ГрузСервис 72» — грузоперевозки, переезды и вывоз мусора в Тюмени

Статический сайт без бэкенда: чистый HTML + CSS + JS. Работает на любом хостинге
(хостинг, VPS, Cloudflare Pages, Netlify, Timeweb, Beget — что угодно, где отдаются файлы).

## Структура

```
site/
├── index.html            — главная (калькулятор, услуги, отзывы, FAQ, районы)
├── vyvoz-musora.html     — вывоз мусора
├── pereezd.html          — квартирные и офисные переезды
├── ceny.html             — полный прайс-лист
├── kontakty.html         — контакты, районы, реквизиты
├── privacy.html          — политика конфиденциальности
├── 404.html              — страница ошибки
├── robots.txt
├── sitemap.xml
└── assets/
    ├── css/style.css     — вся дизайн-система
    ├── js/site-config.js — ← СЮДА ВПИСЫВАЕШЬ КОНТАКТЫ
    ├── js/app.js         — калькулятор, меню, аккордеон, анимации
    └── img/              — favicon.svg, og-image.svg
```

## Ценовая модель (текущая)

| Услуга | Ставка |
|---|---|
| Газель 3, 4, 5 или 6 м | 1 600 ₽/час |
| Грузчик | 700 ₽/час |
| Дополнительный грузчик | 700 ₽/час |
| Комплект «Газель + 2 грузчика» | от 2 800 ₽/час |
| Минимальный заказ | 1 час |
| Упаковка и разборка мебели | от 700 ₽/час (те же грузчики) |
| Такелаж, подъём без лифта, вторая машина | по звонку |
| Вывоз мусора | фиксированной цены нет, от 3 500 ₽, точная сумма — по звонку |
| Переезд + вывоз мусора (комплекс) | −15% |

Переездов «под ключ» нет — только почасовая оплата. Автопарк: только Газели 3, 4, 5 и 6 м
(открытые, тентованные, с конниками). Подача машины — от 30 минут.

## Где менять цены

1. **Калькулятор на главной** — `assets/js/app.js`, объект `PRICE`:

```js
var PRICE = {
  move: {
    truck: 1600,   // Газель, ₽/час
    loader: 700,   // один грузчик, ₽/час
    bundle: 2800,  // комплект «Газель + 2 грузчика», ₽/час
    minHours: 1
  },
  trash: { min: 3500 }
};
```

   Логика: 1 грузчик — `truck + loader`; 2 и больше — `bundle + loader × (грузчиков − 2)`.

2. **Прайс-таблицы в HTML** — они свёрстаны вручную, поэтому правятся в файлах:
   - `index.html` → раздел «Цены» (две таблицы: переезды и вывоз мусора);
   - `ceny.html` → полный прайс на три вкладки;
   - `vyvoz-musora.html` → блок «Вывоз мусора: как считаем»;
   - `pereezd.html` → блок со ставками.

3. **Тексты и SEO** — цены дублируются в FAQ, в SEO-текстах в подвале,
   в `<title>`, `<meta name="description">` и в микроразметке Schema.org
   (блок `FAQPage` в `index.html`). После смены цены пройдись поиском по папке `site/`
   по старой цифре, например `2 800`.

## Что заменить перед запуском

### 1. Контакты — один файл

Открой `assets/js/site-config.js` и впиши:

```js
brand: 'ГрузСервис 72',
legalName: 'ИП Иванов И. И.',
phone: '+7 (912) 000-00-00',
phoneHref: '+79120000000',
telegram: 'my_login',      // пусто — блок скрывается
whatsapp: '79001234567',   // пусто — блок скрывается
metrikaId: '12345678',     // Яндекс.Метрика — можно пусто
yandexVerify: 'код-из-вебмастеров'
```

Сайт подставит эти значения в шапку, подвал, кнопки «Позвонить» и мобильную панель.

> **Важно для SEO:** те же телефон и название продублированы в HTML-файлах
> (поисковики читают текст страницы, а не JS). После правки конфига
> сделай поиск и замену по папке `site/`:
> `+7 (912) 000-00-00` → твой номер, `ГрузСервис 72` → твоё название,
> `+79120000000` → твой номер без пробелов (в `href="tel:..."`).

### 2. Отзывы

В `index.html` есть три отзыва — они демонстрационные. Замени их на реальные:
найди блок с классом `revs` и отредактируй тексты.

### 3. Адрес и карта

На `kontakty.html` в блоке «База» стоит заглушка. Замени на реальный адрес
и вставь карту (Яндекс.Карты iframe или конструктор):

```html
<iframe src="https://yandex.ru/map-widget/v1/?..." width="100%" height="400" frameborder="0" allowfullscreen></iframe>
```

### 4. Реквизиты

На `kontakty.html` в блоке «Реквизиты» — примерные данные (ИНН, ОГРНИП).

### 5. Домен и аналитика

- В `robots.txt` и `sitemap.xml` указан адрес `https://andreyka-batareyka.github.io/gruzservice72/` — если заведёшь свой домен, поменяй его на свой.
- Яндекс.Вебмастер: добавь сайт, подтверди через `yandexVerify` в конфиге.
- Яндекс.Метрика: вставь ID в `metrikaId` (или добавь счётчик вручную в конец `<body>`).
- Google Search Console: подтверди сайт через `google-site-verification`.

### 6. OG-картинка

`assets/img/og-image.svg` — заглушка. Для красивой картинки в соцсетях
сделай PNG 1200×630 и замени файл + путь в `og:image` во всех HTML.

## Как запустить локально

Открой папку `site/` двойным кликом (index.html) — сайт откроется в браузере.
Для проверки вёрстки и работы ссылок лучше через локальный сервер:

```powershell
cd "C:\Users\Admin\Desktop\ZCodeProject scalp\site"
python -m http.server 8000
```

и открыть http://localhost:8000

## Как опубликовать

**Вариант А — обычный хостинг (рекомендую для SEO в Яндексе):**
загрузите содержимое папки `site/` в папку `public_html` или `www` на хостинге
(панель ISPmanager, cPanel, FileZilla).

**Вариант Б — бесплатно и за минуту:**
- Cloudflare Pages: загрузите папку `site` в репозиторий, Pages → Connect to Git → выбери репозиторий → Build command оставьте пустым, Output directory `site`.
- Netlify: перетащите папку `site` на app.netlify.com/drop.

## Что уже учтено

- Мобильная вёрстка, закреплённая панель «Позвонить / Рассчитать» на мобильных.
- Калькулятор с живым расчётом цены в двух режимах (переезд / вывоз мусора) и кросс-скидкой 15%.

- SEO-тексты с ключами «вывоз мусора Тюмень», «квартирный переезд Тюмень», список районов города.
